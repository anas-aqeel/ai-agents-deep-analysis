## Overview

Coolify is a self-hosted PaaS that lets you deploy static sites, full-stack apps, databases, and 280+ one-click services on any server accessible via SSH. One-command install: `curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash`. Free SSL, git-based deployments, PR preview environments, multi-server management, and automatic backups — all without vendor lock-in.

## Key Features

- **280+ One-Click Services** — PostgreSQL, Redis, WordPress, Ghost, Plausible, n8n, Supabase, MinIO
- **Git Deployments** — GitHub, GitLab, Bitbucket auto-deploy on push
- **PR Preview Deployments** — Auto spin-up per pull request
- **Free SSL** — Let's Encrypt auto-provisioned via Traefik/Caddy
- **Multi-Server** — Manage resources across multiple servers from one dashboard
- **Agent-less** — Pure SSH, no daemon on target servers
- **No Vendor Lock-in** — Everything persists even if you remove Coolify
