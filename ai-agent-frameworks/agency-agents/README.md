## Overview

Agency Agents is a massive collection of structured AI agent personality files organized across 12+ divisions (Engineering, Design, Marketing, Finance, Game Dev, Spatial Computing, etc.). Each agent is a markdown file with persona, communication style, workflows, deliverables, and success metrics. One-command installer auto-detects your tools and deploys to all supported platforms. NOT a framework — it's the world's largest agent persona library.

## Key Features

- **144+ Agents** — Engineering, Design, Marketing, Sales, Product, QA, Finance, Game Dev, Spatial Computing, Academic
- **11 Platforms** — Claude Code, GitHub Copilot, Cursor, Aider, Windsurf, Antigravity, Gemini CLI, OpenCode, OpenClaw, Qwen, Kimi
- **Interactive Installer** — Auto-detects tools, parallel processing, platform-specific conversion
- **Structured Format** — YAML frontmatter + Persona (identity, style, rules) + Operations (mission, deliverables, metrics)
- **Chinese Translations** — 46 China-market specialized agents
