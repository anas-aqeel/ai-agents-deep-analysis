## Overview

Onyx (formerly Danswer) is the leading open-source enterprise AI assistant. Agentic RAG, deep research, custom agents, 40+ connectors (Slack, Google Drive, Confluence, Jira, Notion, GitHub, SharePoint, Salesforce), and any LLM backend. Self-hosted via Docker with Onyx Lite (<1GB RAM option) for easy evaluation.

## Key Features

- **Deep Research** — Multi-step autonomous research with sourced reports
- **40+ Connectors** — Slack, Drive, Confluence, Jira, Notion, GitHub, SharePoint, Salesforce, Zendesk
- **Custom Agents** — Specialized personas with designated knowledge bases and tool access
- **LLM Agnostic** — OpenAI, Anthropic, Gemini, Ollama, vLLM
- **Code Execution** — Sandboxed environment for data analysis
- **Voice Mode** — Speech-to-text and text-to-speech
- **MCP Support** — Model Context Protocol integration
- **Onyx Lite** — <1GB RAM lightweight deployment
